# UC6 Consulter les statistiques d'affluence

**Acteur principal** : Responsable de bureau
**Priorité** : 6

## Préconditions
- Le responsable est connecté.

## Scénario nominal
1. Le responsable ouvre le tableau de bord.
2. Le système affiche, par service et par tranche horaire, le nombre de tickets, l'attente moyenne et le taux d'absence.
3. Le responsable choisit une période (jour, semaine).

## Alternatives
- Aucune donnée sur la période : le système affiche « Aucune donnée ».
