# Revue croisée par une autre équipe

Une autre équipe relit la pull request de UC1 (et de chaque UC par la suite).

## Grille de revue

| Point à vérifier | OK | Remarque |
|---|---|---|
| La pull request est liée à une issue (UC) | | |
| La CI est verte | | |
| Le code respecte les 3 couches (contrôleur, service, accès aux données) | | |
| Le scénario nominal est testé | | |
| Au moins un scénario d'erreur est testé (service inconnu, téléphone invalide, ticket déjà actif) | | |
| Le risque de concurrence est traité et testé | | |
| Les diagrammes PlantUML correspondent au code | | |
| Les noms (classes, fonctions) sont clairs | | |

## Comment faire la revue sur GitHub

1. Ouvrir la pull request, onglet « Files changed ».
2. Commenter les lignes concernées.
3. Cliquer « Review changes » puis « Approve » ou « Request changes ».
